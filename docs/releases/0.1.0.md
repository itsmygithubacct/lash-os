# lash-os 0.1.0

GNU Bash 5.3.15 and all 279 selected bash-os builtins run through the Linux eBPF
JIT. Each portable Linux executable contains its own kernel, QEMU, guest tools,
runtime libraries and required firmware.

Run the executable from a folder to share that folder as writable `/home` in a
small VM. The remaining guest filesystem is temporary. The defaults are two
virtual CPUs, 4 GiB RAM and outbound NAT. Use `--sandbox-network=none` for offline
operation. Files changed under `/home` persist in the host folder.

## Downloads and requirements

| Executable | Status | CPU requirement |
| --- | --- | --- |
| `lashos-0.1.0-linux-x86_64` | Primary tested target | x86_64 with hardware virtualization |
| `lashos-0.1.0-linux-aarch64` | Experimental | ARM64 with LSE atomics exposed through KVM |
| `lashos-0.1.0-linux-riscv64` | Experimental | RISC-V64 with Zacas exposed through KVM |

All hosted launches need Linux, access to `/dev/kvm`, Landlock ABI 6 (normally
Linux 6.12 or later with Landlock enabled), and executable temporary storage
outside the shared folder. Run as an ordinary user. Missing isolation support
stops startup. Production launchers require KVM; they do not use software CPU
emulation automatically.

Only the executable is required to run. The matching JSON files are inventories.
Use `SHA256SUMS` to verify downloaded assets. To check one executable:

```sh
sha256sum --check --ignore-missing SHA256SUMS
chmod +x lashos-0.1.0-linux-x86_64
./lashos-0.1.0-linux-x86_64 --version
```

The release includes `lashos-0.1.0-source.tar.zst` and
`lashos-0.1.0-dependency-sources.tar.zst`. Together they provide the corresponding
sources and build recipes for the distributed components. See
[SOURCES.md](https://github.com/itsmygithubacct/lash-os/blob/v0.1.0/docs/SOURCES.md).

## Validation

All three static outer loaders passed seven host test groups. ARM64 and RISC-V64
host tests used user-mode emulation. All three binaries contain the same BPF
image and passed target guest boot and registration of all 279 selected builtins.

| Target | Verified behavior | Remaining validation |
| --- | --- | --- |
| x86_64 | Native KVM boot and all 15 production sandbox groups, including shared home, persistence, processes, networking, streams, terminal jobs, confinement and cleanup | Coverage is limited to the documented test cases and builtin feature subsets |
| ARM64 | Emulated boot; native KVM core shell/builtin cases, networking, terminal jobs and production guest init, home, NAT, pipelines, subshells, background jobs, coprocesses and process substitution | Full production launcher confinement on a supported host; the complete combined builtin suite was not rerun after its HTTP fixture timeout was corrected |
| RISC-V64 | Emulated boot, production guest initialization, shared home, networking and stream smoke checks, and 1,053 upstream BPF instruction tests with zero failures (1,041 JIT-compiled) | Native KVM and host confinement; complete process and terminal job tests |

The older ARM test host correctly refused production sandbox startup because
Landlock ABI 6 was unavailable. Native guest tests used the bundled QEMU
explicitly. Those results do not certify the production launcher's confinement.
The HTTP fixture's readiness allowance was increased, and its network group
passed separately. The final RISC-V smoke suite deliberately omitted process cases.

## Boundaries

Native plugins and worker threads remain deferred. Forks load another verified
BPF image and can be slow. The shared folder has the host user's permissions
and no imposed storage quota. Outbound networking can reach Internet, LAN and
host services; it does not filter destinations. The main shell's exit ends the VM
and its guest jobs.

The bundled Linux kernel is 6.18.52. The RISC-V build contains the documented
JIT zero-extension and address-window patches, plus a BTF variable-record
workaround. The verifier remains enabled. Read
[COMPATIBILITY.md](https://github.com/itsmygithubacct/lash-os/blob/v0.1.0/COMPATIBILITY.md)
and [patches/README.md](https://github.com/itsmygithubacct/lash-os/blob/v0.1.0/patches/README.md)
for details.
