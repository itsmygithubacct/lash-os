# lash-os 0.1.2.1

This release embeds [bash-os v0.1.2](https://github.com/itsmygithubacct/bash-os/releases/tag/v0.1.2)
at commit `8381e8136626d18083d470ac26ba079ad0b2f602`. GNU Bash 5.3.15 and all
286 selected full-profile builtins run through the Linux eBPF JIT.

The first three lash-os version components now match bash-os. A fourth component
records lash-os updates while the upstream release stays unchanged: `0.1.2.1`,
`0.1.2.2`, and so on. The already published lash-os 0.1.2 embedded an older
bash-os snapshot; this correction leaves that historical tag intact.

## Changes

- Update the vendored full profile to bash-os 0.1.2, including `git`, `base64`,
  `sha256sum`, `gzip`, `tar`, `clear` and `bashclear`.
- Reject mismatched version metadata during builds. Release candidate packaging
  checks the latest published bash-os tag and its exact commit. Executable
  inventories record the upstream release identity.
- Support the newer builtins' Git date formatting, descriptor-relative renames,
  file-range copies, named semaphores and message queues through the checked
  userspace bridge. Mount `/dev/shm` and `/dev/mqueue` in the VM.
- Move large service-manager restart and Git remote tables to unwind-managed heap memory,
  and include the GNU sed regex license notice with the runtime.
- Flush calculator output before waiting for the next terminal input, so `bc`
  displays results immediately and returns to the shell on `quit`.
- Add regressions for version policy, timezone conversion, named semaphore
  lifetime and fork inheritance, archive and hash tools, Git commits and dates,
  calculator exit, IPC creation, and service workspace cleanup.

## Downloads

| Executable | Status | CPU requirement |
| --- | --- | --- |
| `lashos-0.1.2.1-linux-x86_64` | Primary target | x86_64 with hardware virtualization |
| `lashos-0.1.2.1-linux-aarch64` | Experimental | ARM64 with LSE atomics exposed through KVM |
| `lashos-0.1.2.1-linux-riscv64` | Experimental | RISC-V64 with Zacas exposed through KVM |

Hosted launches require Linux, access to `/dev/kvm`, Landlock ABI 6, and executable
private temporary storage outside the shared folder. Run as an ordinary user.
The pinned Linux 6.18.52 kernels and runtime dependency versions are unchanged.

```sh
sha256sum --check --ignore-missing SHA256SUMS
chmod +x lashos-0.1.2.1-linux-x86_64
./lashos-0.1.2.1-linux-x86_64 --version
```

The project and dependency source archives together provide the corresponding
sources and build recipes. See [SOURCES.md](https://github.com/itsmygithubacct/lash-os/blob/v0.1.2.1/docs/SOURCES.md).

## Boundaries

ARM64 and RISC-V64 remain experimental. Emulated tests do not certify native KVM
or production launcher confinement on those hosts. Native plugins and worker
threads remain deferred. Forks load another verified BPF image and can be slow;
a nested shell must complete both fork restoration and exec startup.

The launch folder is writable `/home`; other guest files are temporary. Outbound
networking is enabled by default. See [COMPATIBILITY.md](https://github.com/itsmygithubacct/lash-os/blob/v0.1.2.1/COMPATIBILITY.md)
for the detailed feature and platform boundaries.
